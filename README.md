# UberNotes
UberNotes is a note taking webapp, designed for ease of use.

## Run on Windows
Double-click `Start UberNotes.bat` to open UberNotes in your default web browser (the browser configured for web links, not the `.html` file association). The launcher opens the app beside itself when possible; otherwise, it searches local fixed drives for `UberNotes-main\index.html`. Keep `Start UberNotes.bat`, `OpenUberNotes.ps1`, and the app files together in the same folder. No installation is required.
